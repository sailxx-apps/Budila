<summary><b>기능에 대해 자세히 알아보기</b></summary>

### ⏰ 메인 화면

현재 시간과 날짜가 상단에 "10월 6일 화요일"로 크게 표시됩니다. 아래는 **“다음 알람”** 카드: 요일, 시간, 남은 시간. 알람은 10가지 색상 중 하나로 칠할 수 있으며 다음과 같이 표시할 수 있습니다. **태그** — 필터 행(“모두 · 5”, “작업 · 2”)에는 필요한 항목만 표시됩니다.

### ✏️ 편집자

시간을 설정하세요. **소재 3 다이얼** 아니면 키보드로. 라벨링, 평일 반복, 태그(기성품 또는 직접 제작), 카드 색상, 진동 및 **부드러운 잠에서 깨어나다**. 삭제된 알람은 한 번의 탭으로 다시 나타납니다.

### 🌿 부드러운 기상

알람은 거의 무음으로 시작되고 약 1분 동안 볼륨이 부드럽게 커지다가 30초 후에 진동이 시작됩니다. 모드가 켜지고 꺼집니다 **각 알람마다 별도로**; 설정에 따라 어떤 새로운 알람이 수신될지 결정됩니다.

### 🔔 울리는

벨이 울리는 화면이 저절로 디스플레이를 켜고 열립니다. **잠금화면 너머**. **“해고하다”** 그리고 **“선잠”** (5~20분 동안)이 화면과 알림에 표시됩니다. 아무도 응답하지 않으면 5~30분 후에 알람이 자동으로 꺼집니다.

### 🧮 “악기” 디자인

Budila만의 스타일로 디자인한 [Okto](https://github.com/sailxx/Okto): 엔지니어링 계산기와 같은 단색 케이스, 실제 키 및 매립형 디스플레이. 숫자는 "불이 꺼진" 8개와 출시 시 자체 테스트가 있는 JetBrains Mono이며, 시간은 키패드에 입력되고 울리는 알람은 빨간색으로 빛납니다. 9가지 테마 — 클래식(라이트, 다크, OLED ), 페이퍼, 민트, 사쿠라, 미드나잇, 오션, 노드, 크림슨, 앰버. 기본적으로 켜져 있습니다. Material 3은 설정에서 다시 가져올 수 있습니다.

### 🎨 테마

8개 테마: **재료 당신** 배경 화면에서 인디고, 바다, 숲, 일몰, 사쿠라, 흑연 및 **관습** — 색상환에서 색상, 채도 및 스타일(차분함, 생동감, 표현력, 무지개…)을 선택하세요. 밝거나 어둡거나 시스템을 따르며 AMOLED의 경우 순수한 검정색 배경을 추가합니다.

### 🌍 10개 언어

러시아어, 영어, 우크라이나어, Español, Português, Deutsch, Français, Italiano, Türkçe, Polski. Android 13+에서는 Budila의 언어를 시스템과 별도로 선택할 수 있습니다.

### 🛡 신뢰할 수 있음

알람은 시스템을 통해 설정됩니다. `AlarmClock` 전화기가 잠자기 상태일 때에도 정시에 벨이 울립니다. 재부팅하거나 시간이나 시간대를 변경하면 Budila가 이를 다시 설정합니다.

<summary><b>설치하다</b></summary>

1. 다운로드 [**Budila.apk**](https://github.com/sailxx/Budila/releases/latest/download/Budila.apk) 당신의 휴대 전화에.
2. 파일을 열고 이 소스에서 설치를 허용합니다.
3. 처음 시작할 때 알림을 허용하세요. 알림이 없으면 벨소리 화면이 나타나지 않습니다.

Android 8.0 이상이 필요합니다. Google Play도 없고 계정도 필요하지 않습니다.

Budila도 있습니다 [코미스토어](https://github.com/komi-store/komi-store), GitHub 릴리스를 기반으로 구축된 앱 스토어: "Budila"를 검색하면 Komi Store가 자동으로 업데이트를 제공합니다.

</details>
